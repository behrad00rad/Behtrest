## This is a pintrest clone I made for fun.
#### disclamer : this porject will have updatesin the future

its frontend is made by react.js and tail wind css and its using python (flask) for backend.
you can share posts (pictures and in .jpg  or .png format only) and leave your comments in it for everyone else to see.
you can login o register you account and your password will be hashed and secured in the database,and you would get a default profile picture.
